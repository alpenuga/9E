# 9E
--------------
PWA-приложение (Progressive Web App) 
с экспортом/импортом JSON, умными ответами, разделением по предметам, загрузкой нескольких файлов, улучшенным поиском (BM25) и поддержкой PDF-учeбников.
---------------
Приложение работает полностью офлайн, устанавливается на устройство как обычное приложение.
